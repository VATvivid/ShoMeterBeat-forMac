# re-minimeter

Windows에서 나는 모든 소리(브라우저, 게임, REAPER 같은 DAW, 언리얼 같은 게임 엔진)를
시스템 루프백으로 받아 실시간으로 보여 주는 오디오 비주얼 아날라이저 + EBU R128 라우드니스 미터.

## 모듈
- **Spectrum** — 20 Hz~20 kHz 로그 스펙트럼(피크 홀드, 4.5 dB/oct 틸트). 우클릭 "채널": L/R 최대(한 곡선) · **LR 모드**(L·R 두 곡선) · **MS 모드**(Mid·Side — 엔진이 L/R 복소 스펙트럼에서 (L±R)/2를 따로 보냄). "색상"에 프리셋 6종(기본·불꽃·오로라·무지개·아이스·네온)
- **Spectrogram** — 스크롤 스펙트로그램. 우클릭 "색상 테마" 6종(앱 테마·불꽃·비리디스·아이스·흑백·마그마), "감도(바닥 dB)"로 노이즈 바닥을 잘라내고 "대비(감마)"로 색 분포를 당기거나 편다.
- **Oscilloscope** — 트리거 오실로스코프(L/R)
- **Stereo** — 리사주(벡터스코프) + 상관 미터
- **Levels** — 헤더에서 Peak / True Peak / RMS / LUFS(M·S) 선택, 피크 홀드, 클립 표시. 둥근 트랙·세로 그라데이션(신호색 → 상단 주황 → 클립 빨강)·반투명 RMS 코어·은은한 홀드 선, 릴리스 24 dB/s
- **Loudness** — (기본 폭 12칸) 왼쪽부터 **실시간 LUFS 미터**(Levels처럼 M/S 막대, 타깃 선, 피크 홀드, 타깃 초과 빨강), **분포**(Dynamics처럼 60초간 Short-term의 1 LU 히스토그램 + 중앙값, 미터에 붙여 배치), **볼륨 흔적**(Waveform처럼 최근 60초 — Short-term을 아래에서 채운 띠, Momentary를 선으로, 타깃 점선), 오른쪽에 읽기값(Integrated·Range·Momentary·Short-term·True peak max·타깃·초기화 버튼). 좁아지면 분포 → 미터 순으로 빠짐. 기존 설명: Momentary / Short-term / Integrated / LRA / True Peak + 60초 히스토리, 타깃 프리셋(YouTube/Spotify −14, 팟캐스트 −16, −18, EBU −23, ATSC −24)
- **Vocal Tract** — 들어오는 소리에서 LPC로 추정한 F1/F2를 **보정된 모음 조음표**(22개 모음 × 남/여/아동, 혀 몸통·혀끝·턱·입술·후두 값, chimera-vocal-synth 데이터·MIT)에 대어 가장 가까운 4개를 섞어 측면도를 움직인다. 턱은 과두를 축으로 회전, 혀는 몸통 원+혀끝, 입술은 개구·돌출, 후두는 모음과 피치에 따라 오르내림. 디테일: 혀·턱·입술 잔상, 기도 압력 열색, 최소 협착 캘리퍼(cm), 성대 f0 진동, 척추·기관·설골·비강·눈(시선·깜빡임, 고음에서 위로). **호흡·마찰음**은 잡음도(스펙트럼 평탄도)와 밝기(스펙트럼 중심)로 잡아 성대를 벌리고 흰 난류 점을 뿌린다(어두운 "h"는 성문, 밝은 "s/f"는 치아·입술). 규칙적인 숨은 분당 호흡수로, 폐 게이지는 추정 폐활량. 우클릭에서 음성 유형(남/여/아동).
- **Vowel Map** — F1–F2 모음 포먼트 지도(IPA 기준 모음 10개, 실시간 마커와 1.5초 궤적, 가장 가까운 모음 표시)
- **Pitch** — 두 모드(우클릭 "모드"): **음성 전용**은 엔진의 유성음 f0 추적, **효과음 전용**은 실시간 스펙트럼의 최강 피크(포물선 보간)를 톤 문턱(중앙값 대비 ≥12 dB·평탄도)으로 걸러 스윕·타격음 몸통·UI 블립·드론의 음높이를 따른다. 기존 설명: 피아노롤식 노트 블록(반음 단위로 묶음) + 정확한 피치 곡선, 음이름·센트 편차, 자동 음역 추적(1~3옥타브), 시간 범위 5~30초
- **Dynamics** — Levels식 세로 막대 3개: Crest(피크−RMS), PSR(최근 3초 True Peak − Short-term LUFS), PLR(세션 최대 TP − Integrated). 6 dB 미만 빨강·10 dB 미만 주황 구간. 각 막대 옆에 최근 15초~5분의 **분포 프로파일**(1 dB 히스토그램)과 중앙값(노란 선)
- **BPM Checker**(구 Transient) — 엔진의 10 ms 스펙트럼 플럭스로 온셋 검출(감도 σ 배수), 템포는 6초 자기상관을 시간 누적(감쇠)한 템포그램 + 배수 합산 + 장르 사전확률 + 연속성(새 템포는 2회 반복 시 채택). 82 BPM 시네마틱 데모에서 ±3 BPM 65%(이전 12%)
- **Stereo Bands** — 저(<150)/중저/중/고 대역별 상관(−1…+1)과 폭(사이드 비율), 저역 모노 호환 경고
- **Variation Map** — 엔진이 온셋마다 클립(−20~+320 ms)을 잘라 58차원 특징을 뽑는다: **스펙트로-템포럴 패치**(4 시간 슬라이스 0–60/60–120/120–200/200–340 ms × 12 바크 밴드쌍, 클립 평균 대비 dB — 밴드별로 어택·몸통·꼬리가 어떻게 움직이는지), 중심·대역폭·롤오프·평탄도, 어택·감쇠·길이, 크레스트·피크·ZCR. 모듈은 이를 **세 그룹 — 음색(밴드 평균+스펙트럼 서술자) · 시간(패치의 밴드별 포락선 편차+어택/감쇠/길이) · 세기(크레스트·피크)** 로 나눠 각 그룹의 총 가중치를 같게 맞춘 뒤(우클릭 슬라이더 ×0~2) 표준화 → PCA 2D → 온라인 군집(반경 설정)으로 점을 찍는다. 밝기만으로 축이 정해지지 않게 하기 위한 구조다. 지도 아래 **신규성 띠**: 히트마다 직전 같은 군집 히트와의 거리를 군집 반경 대비 %로 막대 표시(동일 판정 거리 이하면 빨강, 새 군집이면 빈 막대), 글자는 가장 달라진 그룹(음/시/세). 같은 소리(군집)가 **서로 다른 베리에이션으로 연속**되면 지도 오른쪽 위에 **VARIATION COMBO ×N**이 올라가고(×2 청록 → ×5 주황 → ×10 노랑, 새 점에서 터지는 링·빛살도 커짐), 같은 소리가 거의 똑같이 반복되면 **REPEAT ✕**로 콤보가 끊기며 최고 콤보가 남는다. 30초 넘은 점은 작고 흐리게, 군집 라벨은 2개 이상 모인 군집에만. 같은 군집이 연속 N회 거의 같은 특징으로 터지면 **반복 감지 경고**. 발소리·피격·총성 랜덤화가 실제로 다르게 들리는지 보는 용도. 외부 모델 없음
- **Subtitles** — whisper.cpp(로컬 CPU)로 들어오는 말소리를 자막으로. 레벨 게이트로 발화를 나눠(0.6~10초) 끝날 때마다 인식하므로 **2~6초 지연**. 언어 자동/한국어/영어/일본어/중국어, 모델 base(빠름)·small(정확, 한국어 권장)·medium, TXT/SRT 저장. 모델은 설치본에 없음: `python scripts/fetch_models.py --whisper small` 또는 `%APPDATA%\re-minimeter\models\ggml-small.bin`
- **Player** — 파일의 템포가 구간마다 다르면(8초 창·2초 간격으로 재추정, 4 % 이상 달라지고 두 창 연속이면 새 구간) 파형 위에 **BPM 마커**(점선 + "128 BPM")가 구간 시작마다 붙는다. 기존 설명: 오디오 파일(WAV·AIFF·FLAC·MP3·OGG·AAC)을 타일에 **끌어다 놓으면** 전체 파형과 재생 컨트롤(▶/⏸, ■, ↻ 반복, 파형 클릭으로 탐색). 재생은 Web Audio로 기본 출력 장치에 나가므로 루프백 모드면 다른 모듈이 같이 반응한다. 파일 전체를 오프라인 분석해 길이·SR·채널·**LUFS-I·LRA·True Peak·Peak·RMS·Crest·BPM(신뢰도·구간 일치율)** 을 표시(최대 10분)
- **Spectrum 레퍼런스** — 우클릭 "레퍼런스 추가…" 또는 **Spectrum 타일에 파일을 드롭**하면 파일의 평균 스펙트럼을 프리셋(파일명)으로 저장, 선택하면 노란 점선으로 겹쳐 보임. "레벨 자동 맞춤"은 100 Hz~10 kHz 중앙값을 라이브에 맞춰 재생 레벨 차이를 지움. 포맷은 Player와 같음
- **Waveform · AI 태그** — 우클릭 "AI 태그 (YAMNet)"를 켜면 Google YAMNet(AudioSet 521 클래스, ONNX, 로컬 CPU)이 0.5~2초마다 최근 1초를 분류해 파형 위에 마커(라벨·점수)를 찍는다. 필터(음성/음악/효과음/기타)·최소 점수·간격 조절, 끄면 비용 0. 모델은 `scripts/fetch_models.py`로 `src-tauri/models/`에 받는다(설치본엔 포함)
- **Waveform** — 최근 2~120초 파형(min/max 포락선). dB 스케일은 ± 대칭이 아니라 **아래에서 올라오는 레벨 이력**(0 … −60 dBFS)으로 그린다. 타일 안을 **드래그하면 스크롤이 멈추고** 구간이 선택되며, "WAV 저장"으로 그 구간을 엔진의 2분 이력에서 32-bit float 스테레오 WAV로 렌더해 저장한다(Esc·취소로 재개). **"↗ DAW로 끌기"** 버튼을 누른 채 REAPER 등 DAW 트랙에 끌어다 놓으면 그 구간이 WAV로 배치된다 — 파일은 클립 폴더(기본 `문서\re-minimeter\clips`, 우클릭에서 변경)에 남는다(DAW가 그 경로를 참조하므로 지우지 않는다; 끌기를 취소하면 삭제)
- **Emoji** — 재미용 16×16 도트 스프라이트(2026-11-13부터 20 % 작게). 트랜지언트가 튀면 스프라이트 뒤에서 플래시·충격파 링·임팩트 라인이 터지는데 **크기·굵기·갈래 수가 세기(레벨 점프 9~29 dB)에 비례**한다. 규칙 모드는 엔진이 이미 보내는 값(레벨·유성음/f0·F1/F2·평탄도·중심)만 써서 비용 0: 말소리면 모음대로 입 모양이 바뀌는 얼굴, 비트가 있으면 통통 튀는 음표/드럼, 트랜지언트는 밝기·노이즈로 칼·쿵·반짝·탁, 지속 노이즈는 바람, 조용하면 자는 얼굴. AI 모드는 YAMNet 태그(Waveform AI 태그와 모델 공유)로 개·고양이·차·물·종·번개·불·새·총성·발소리 등
- **Punch Machine**(구 Punch) — 타격음·UI음이 **얼마나 세게 들리는지**의 절대 척도. 기본 보기는 **펀칭 머신**: 오락실 펀치 기계처럼 램프 탑이 히트 순간 위로 치솟았다 내려오고(약함/보통/강함/아주 강함/KO 구간), 세 자리 **SCORE**(강도 지수 × 9.99)가 올라가며 세운 등급 단어와 세션 **BEST**(갱신 시 NEW RECORD! 점멸), 직전 대비 ▲▼, 글러브가 붙는다. 우클릭 "표시 → 분석"으로 아래 상세 보기(옥타브 프로파일·이력·PM95)로 전환. Fenton & Lee의 지각적 punch 모델(AES 138/139, JAES 2019; 저자들의 "Perceptual Punch Tool"과 같은 계열)을 엔진에 구현: 미디언 필터로 트랜지언트만 분리(βt = 3) → 수정 BS.1770 가중(RLB 하이패스 + 1 kHz/+10 dB 셸프) → 옥타브 밴드 에너지에 회귀 가중 `EstPunch = 0.954 − 0.171·Band − 0.088·Onset`(63 Hz…1 kHz, 어택 0…60 ms) → 280 ms 블록 평균 → **dB(0 = 풀스케일 정현파 에너지, 정현파 = −3 dB)**. 지속음은 트랜지언트가 없어 −∞. 온셋(플로어·감쇠 포락선 대비 +8 dB)마다 **히트** 하나: **타격(punch) dB**, **무게(body) dB**(500 ms 히트 전체의 청감 가중 에너지 — 트랜지언트 블록이 못 보는 몸통·꼬리), 어택 ms, 옥타브 프로파일, 피크, 그리고 **화려함 0–100**(이 앱 고유 휴리스틱 — 고역 비중 35 % · 옥타브 커버리지 25 % · 스테레오 폭 25 % · 꼬리 15 %). 큰 숫자·히트 막대·글러브가 따르는 **강도**는 기본 "타격 35 % + 무게 65 %"(dB 합성, 우클릭에서 타격만/무게만으로 변경)를 **0–100 지수**로 바꾼 값인데, 지수는 −45 dB → 0, −10 dB → 100에 γ = 2로 **고점이 조밀**하다 — 게임 타격음은 피크가 모두 같아 몇 dB 차이로만 갈리므로 그 몇 dB를 벌려 보여 주기 위해서다. 실제 타격음 36개(normal/double/critical 등급)로 보정했다: 타격만으로는 등급이 ±2 dB로 평평했고 무게가 등급마다 2~3 dB씩 계단으로 올라갔다. 숫자는 절대값이지만 **글러브 크기와 막대·숫자 색은 화면에 있는 최근 히트들의 범위에 상대적**(최소 20점 폭)이라 몇 점 차이도 눈에 띈다 — 가장 약한 히트는 작고 흐리게, 가장 센 히트는 크고 따뜻한 색(약/중/강 3단, 우클릭에서 절대 표시로 전환). 큰 숫자 옆에 직전 히트 대비 ▲▼. 오른쪽 **복싱 글러브 이모지**(자기 칸)는 강도가 셀수록 커지고(히트 순간 앞으로 찌름), 화려할수록 주변 빛무리가 밝고 넓어지며 꽤 화려하면 돌아가는 빛살이 더해진다(우클릭에서 끌 수 있음). 히트 막대를 **클릭하면 기준**이 되어 이후 히트에 "기준 대비 +12"가 뜬다(A/B 비교). 세션 통계 PM95(상위 5 % 프레임)·평균·PM95M(= PM95 − 평균)은 punch 기준. 오프라인 측정: `cargo run --release --example punch -- <파일 또는 폴더>`

모듈은 켜고 끌 수 있고(모듈 ▾의 **＋**로 같은 모듈을 여러 개 둘 수 있다 — 예: Pitch 하나는 음성, 하나는 효과음 모드. 추가 인스턴스는 "Pitch (2)"처럼 번호가 붙고 설정이 따로이며, 우클릭 "이 모듈 지우기"로 없앤다), "레이아웃 편집"(E)에서 드래그로 옮기고 모서리로 크기를 바꾼다. 배치는 **겹침 허용** 한 가지: 놓는 자리에 그대로 놓이고 다른 타일은 전혀 움직이지 않으며 겹쳐도 된다(끌어 올린 타일이 위로 올라옴). 자리 바꾸기·밀어내기 모드는 제거했다. 드래그 중에는 점선 가이드로 도착 자리만 보여 주고 놓을 때 이동한다. 그리드 확장: 편집 모드에서 오른쪽 가장자리의 **+/−(열)**, 아래 가장자리의 **+/−(행)** 버튼으로 칸을 늘리고 줄인다(창 크기는 그대로, 칸이 작아짐; 타일이 쓰는 칸은 항상 포함되고, 늘린 값은 저장된다). 끌리는 타일은 포인터를 1:1로 따른다. 배치는 저장된다.

## 별도 창 · 항상 위 · 투명도
- **창 ▾** 메뉴: 메인 창 **항상 위**(📌), **투명도** 0~100 %(기본 100) — **투명 방식**이 "배경만"(기본)이면 창·타일·헤더의 배경만 투명해지고 글자와 그래프는 그대로 선명하다(창이 투명 모드로 떠 있어 뒤 화면이 비침); "창 전체"면 예전처럼 창 전체가 흐려진다(0은 3 %로 적용). **새 별도 창**, **◎ 창 찾기**(메인 창과 열린 별도 창의 테두리를 두 번 반짝임), 열린 별도 창 목록(앞으로 가져오기 · 닫기).
- **별도 창**은 테두리·툴바 없이 모듈만 보인다. 창 **위에 마우스를 올리면** 얇은 바가 내려온다(편집 중에는 고정): 끌어서 이동, **📌 항상 위 ON/OFF**(켜지면 글자와 테두리가 신호색으로 바뀜), 투명도, 모듈 ▾, 편집(편집 중에는 바가 고정되고 타일이 그 아래로 내려가 겹치지 않음), ◎ 창 찾기, ✕ 닫기(창이 스스로 모듈을 메인 창에 돌려보내고 닫힘). 오른쪽 아래 모서리로 크기 조절. 모듈을 2개 이상 둘 수 있고 배치는 창마다 따로 저장되며 다음 실행 때 같은 자리에 다시 열린다.
- **창 사이 이동**: 레이아웃 편집 모드에서 타일을 끌어 **다른 창 위에 놓으면** 그 창의 그 자리에 배치된다(점선 가이드가 받는 창에 뜬다). 아무 창도 없는 바탕에 놓으면 그 자리에 **새 별도 창**이 열린다. 타일 우클릭 → "별도 창으로 보내기 / 메인 창으로 보내기"도 있다.
- 메인 창을 닫으면 별도 창도 함께 닫힌다.

- **모듈 설정**: 타일 아무 곳이나 **우클릭**(또는 헤더 ⋯) → 그 모듈의 설정. Spectrogram 2D/3D·속도, Spectrum 기울기·범위·피크 홀드, Levels 표시 값, Loudness 타깃, Stereo 잔상.
- **도킹**: 상단 "도킹 ▾"에서 화면 위/아래/왼쪽/오른쪽에 띠 모양으로 붙인다(항상 위, 테두리 없음). 도킹 상태에서는 모듈이 한 줄로 놓이고 배치가 따로 저장된다. 띠 두께는 같은 메뉴에서.

## 도킹
- 도킹 ▾ 위/아래/왼쪽/오른쪽: 창이 그 가장자리의 얇은 띠가 된다. Windows에서는 **AppBar(작업 표시줄 같은 예약 영역)** 로 등록돼 다른 창을 최대화해도 띠를 덮지 않고 그만큼 비켜 선다(MiniMeters 방식). 해제하면 예약을 풀고 원래 창 크기·위치로 돌아온다.
- 띠 안의 모듈은 칸을 쥐어짜지 않고 **스트립이 스크롤**된다(가로 독은 휠로 좌우 스크롤). 모듈 ▾로 켠 모듈은 띠 끝에 붙는다. 띠는 바깥 여백 없이 창 가장자리까지 찬다.

## 소리 입력 선택
상단 드롭다운 기본값은 **자동**이다: 기본 출력 장치의 루프백(브라우저·게임·일반 앱) **+** DAW에 꽂은 `re-minimeter Send` 플러그인 신호를 **합쳐서** 동시에 보여 준다. 손댈 것이 없다.

- **자동 (권장)** — 루프백 + DAW 플러그인. 다른 출력 장치의 루프백을 쓰고 싶으면 같은 묶음에서 고른다.
- **출력 장치만(루프백)** — 그 장치로 나가는 모든 Windows 소리.
- **입력 장치만** — 오디오 인터페이스의 하드웨어 루프백이나 가상 케이블. 플러그인을 꽂을 수 없는 앱(Pro Tools 등)용. Windows "마이크 액세스"가 켜져 있어야 한다.
  - RME: TotalMix FX에서 모니터링 출력(예: AN 1/2)의 **Loopback**을 켜면 같은 번호의 입력("Analog (1+2)")으로 되돌아온다.
- **DAW 플러그인만** — 루프백 없이 플러그인 신호만.

## DAW 플러그인 (re-minimeter Send)
ASIO로 동작하는 DAW(REAPER, Cubase/Nuendo, Ableton, Studio One, Bitwig…)는 Windows 믹서를 거치지 않아 루프백에 안 잡힌다. 대신 트랙이나 마스터에 **re-minimeter Send**를 꽂으면 소리는 그대로 통과하면서 사본이 앱으로 전달된다(공유 메모리, 지연 없음, 여러 개 꽂으면 합산, 최대 8개).

1. 앱 상단 **플러그인 설치** 클릭 → `%LOCALAPPDATA%\Programs\Common\CLAP\` 와 `...\VST3\` 에 복사된다(관리자 권한 불필요).
2. DAW에서 플러그인 재스캔. DAW가 그 폴더를 안 보면 플러그인 경로에 추가한다(REAPER: Preferences → Plug-ins → VST / CLAP 경로).
3. 마스터(또는 원하는 트랙)에 "re-minimeter Send" 삽입. 앱 상태 바의 "플러그인 N"이 올라가면 연결된 것.

- 형식: **CLAP**(ISC) + **VST3**. VST3 래퍼(nih-plug/vst3-sys)는 **GPLv3**이므로 외부 배포 시 라이선스 확인 필요. 사내·개인 사용은 무관.
- **Pro Tools(AAX)는 지원하지 않는다** — Avid 개발자 계약·서명이 필요해 만들 수 없다. 입력 장치(인터페이스 루프백) 경로를 쓴다.
- 플러그인 빌드: `npm run plugin` (crates/rm-send-plugin → src-tauri/plugins/). 설치본(NSIS)에는 자동 포함된다.
